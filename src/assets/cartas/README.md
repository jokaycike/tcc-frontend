# Imagens das cartas

Coloque aqui as imagens das cartas separadas por raridade:

- `comum`: cartas comuns
- `raro`: cartas raras
- `epico`: cartas epicas

Formatos aceitos pelo sistema: `.png`, `.jpg`, `.jpeg`, `.webp` e `.svg`.

Quando houver imagens nessas pastas, o app usa automaticamente uma imagem da mesma raridade da carta. Se nao houver imagem suficiente, ele usa o visual gerado como reserva.
